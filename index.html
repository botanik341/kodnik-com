File protection and undo

Before Kodnik edits or fixes a file, it saves a restore point. After the work is complete, you see a change notice below the code and can use Undo change to restore the file to its state before the edit.

Shared terminal

The same terminal for you and the AI agent.

You and the AI agent use the same project terminal session. You can enter commands manually, and Kodnik can continue working in that same PowerShell, CMD or Git Bash session — running commands, reading results and reacting to errors.

One shared session You and the agent work in the same project terminal — without a separate hidden terminal for the AI.
Full command visibility You see the agent's commands, command output and error messages in PowerShell, CMD or Git Bash.
Shared work on command output You can enter your own command and Kodnik can use its output in the next step — or run a command itself and then fix the code.
Model settings

Context, Thinking and Fast mode.

The most important local-model settings are available from Kodnik's bottom bar.

Small, large or Auto context

Small context keeps work lighter, large context gives the model more room for files and conversation, and Auto manages the setting automatically. The bottle shows how much of the selected context is currently in use — it fills as usage grows, while the percentage below shows the current level.

Thinking or Fast mode

Use Thinking for a more demanding task, or Fast mode when you want a shorter model response.

Under the hood

Kodnik configures itself for your hardware.

On first launch, Kodnik detects available resources, selects the compute backend and distributes model work between the GPU, system RAM and CPU. You do not need to configure runtime parameters manually.

Detects your hardware

Detects a supported GPU, available VRAM, driver version, CPU core count and system RAM before starting the model.

Selects the compute backend

Automatically selects the appropriate GPU acceleration backend — CUDA or Vulkan — or CPU mode when a supported GPU is not available.

Calculates model placement

Calculates how many model layers can be placed in GPU memory and how many should remain in RAM, using available resources without overfilling memory.

Works with different GPU brands

Kodnik can work with GPUs from different manufacturers and can also run on CPU only when needed.

Checks RAM and VRAM

Reads available system memory and GPU memory to configure runtime settings without manual parameter entry.

Safe fallback configuration

If every hardware parameter cannot be detected, Kodnik uses conservative startup settings instead of relying on incomplete data.

FAQ

Questions before purchasing.

What exactly does Kodnik do with my project?

Open a project folder and enter an instruction. Kodnik reads your files, shows a plan and then applies code changes — it can create new files, edit existing ones and fix errors. It saves a restore point before each change.

Do I need an internet connection?

Internet is needed for initial setup and model downloads, and later for updates and ONLINE mode. Working with a local model in OFFLINE mode does not require a permanent connection.

Does Kodnik send my project to an external AI model?

In OFFLINE mode, the model runs locally on your computer and the project is not sent to an external AI model. You deliberately enable ONLINE mode when you want to give Kodnik access to internet tools.

Does it work without a GPU?

Yes. A graphics card is not required. Kodnik can run on the CPU, while a compatible GPU can significantly speed up local model responses.

Am I buying the AI models together with Kodnik?

No. The purchase covers the Kodnik application. The models are independent projects distributed under their own licenses. Kodnik lets you choose supported models, downloads their files and prepares them for local use.

Is there a subscription?

Each payment covers 12 calendar months from term activation. Renewal is manual. The annual license must be renewed after expiry. One account is shared with kodnik.pl and the application. OFFLINE works throughout the valid term without periodic server contact.

Will I receive updates?

Yes. Kodnik has a built-in updater and notifies you when a newer version is available. Updates are included during the paid 12-month term. Earlier purchases retain their original terms.

How long does installation take?

Installing the application itself takes a few minutes. AI models are downloaded locally based on your selection, so download time and required disk space depend on the selected models and your connection speed.

I am not sure whether my computer can run Kodnik. What should I do?

Download the 2-hour DEMO. On your own computer, you can select a model, run it locally and test actual performance before purchasing a Kodnik license.

What are context and response mode used for?

Context controls how much information is available to the model during a task. You can choose small, large or Auto. Thinking mode is intended for more demanding tasks, while Fast mode produces shorter model responses.
